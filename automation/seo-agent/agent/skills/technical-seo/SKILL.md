# Technical SEO

Report observed behavior and uncertainty separately. Validate canonical, robots, sitemap, redirect, schema, metadata, and performance records against the repository inventory or a time-stamped read-only audit. Do not claim preview or production behavior without a verified URL and deployment association. Never use technical SEO to justify hidden content or mass URL creation.
