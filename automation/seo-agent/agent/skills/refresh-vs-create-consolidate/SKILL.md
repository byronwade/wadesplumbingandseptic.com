# Refresh versus create versus consolidate

Start with the canonical owner, Markdown inventory, and link graph. Refresh when an existing page can satisfy the intent, including a contextual internal-link improvement. Consolidate when pages overlap. Create only after a documented failed existing-page assessment, an approved service-area/business fact set, canonical/redirect plan, demand-timing evidence, and human review. Net-new URLs are limited to a blog post or an explicitly approved landing page; never create a service page. Reject city templates, date-only freshness edits, fixed content cycles, and any change that creates duplicate intent. No evidence means no action or a first-party-evidence request.
