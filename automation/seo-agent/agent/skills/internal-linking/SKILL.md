# Internal linking

Use the link graph and canonical ownership. Recommend only visible, contextual links that benefit a reader and point to a valid canonical target. Reject hidden links, paid-link schemes, repetitive anchors, orphaning, and links added only for keywords. State each source, target, anchor rationale, and broken-link check.

## Site architecture notes

- Prefer improving an existing canonical URL before creating a sibling.
- Cluster service → city/service → tip pages so equity flows to money pages.
- Avoid thin templated city pages that only swap the place name.
- When two pages compete for one query, consolidate and redirect rather than splitting equity.
