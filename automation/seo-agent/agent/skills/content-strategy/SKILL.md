# Content strategy

Score only evidence-backed opportunities. Map each cluster to one canonical owner and identify cannibalization risk. Prefer an existing page, link improvement, or consolidation before a new URL. Net-new URLs are normally blog posts; an approved landing page needs a recorded human approval ID. Never propose a new service page. Service work is limited to an evidence-backed refresh of an existing page; generic page work remains manual.

Time blog work from demand, search performance, seasonality, existing coverage, quality, and a named outcome metric, never a fixed cycle or freshness date. A holiday post needs an upcoming holiday, 7–120 days of useful lead time, local-relevance evidence, non-duplicate intent, and an observation window. Every proposal must name its hypothesis, expected metric, counterfactual, contextual links, evidence, factual claims, image provenance when imagery is proposed, and rollback. When support is incomplete, choose no action or request first-party evidence.
