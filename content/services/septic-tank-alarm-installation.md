## Get warning before a high-water event becomes a backup

An alarm provides critical notice when liquid rises above the normal operating range. Causes can include pump failure, float problems, electrical faults, excessive inflow, or a restricted downstream component.

We install properly rated components, verify float elevations and wiring, and test audible and visual alarm operation before completion.
