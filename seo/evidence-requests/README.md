# Evidence Requests

This directory contains non-secret requests for data or approval that cannot be inferred from current repository text. No request is evidence and no request authorizes a business claim.

- `search-console-read-access.md`: read-only Search Console access and property confirmation.
- `service-area-approval.md`: human review of the repository-derived candidate fact registry.
- `vercel-sidecar-setup.md`: a separate Vercel sidecar project, scoped Connect credentials, and preview/production read-only audit access.
