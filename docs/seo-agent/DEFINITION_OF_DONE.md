# Eve SEO Agent Definition of Done

## Machine-Checkable Completion Contract

The implementation is complete only when every applicable check below passes. Live integrations may remain `BLOCKED_MISSING_CREDENTIALS` only when the documented manual prerequisite is unavailable and the full offline/mock suite passes; a real probe failure is `FAILED` and requires a disposition. Neither state may be described as operational. `npm run seo-agent:verify` executes the machine-checkable deterministic rows without network access; the dependency advisory is intentionally a separately labelled non-offline check.

## Human Acceptance Conditions

- A human has reviewed the threat model, allowed domains/commands, tool scopes, service-area fact registry, budgets, prompt/eval changes, and rollback procedure.
- A human has approved every production connector and the first production audit-only run.
- A human has merged every content change; production deployment came from the normal approved `main` flow.
- `IMPLEMENTATION_STATUS.md` includes final commands, exit codes, durations, evidence classifications, failures, and external blockers.

## Stop-Hook Final Gate

The guarded final-verification hook is enabled by `.agents/ENABLE_EVE_SEO_AGENT_STOP_HOOK`. It runs `npm run verify:completion` without writing files. It may emit a continuation signal only if caller-supplied active-state JSON says `goal_active: true`, completion evidence fails, and `continuations_used` is below the sentinel's bounded maximum. Callers must increment that input after a continuation; the hook never retries or mutates work.
